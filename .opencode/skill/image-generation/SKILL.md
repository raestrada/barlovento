# Image Generation (agy / Gemini)

BARLOVENTO has **no human artist**. All art is generated by driving Google's
Antigravity CLI (`agy`, Gemini) headlessly. Coherence comes from the versioned
prompt registry, never from ad-hoc prompts.

## Before generating

1. Read `docs/art/ART_DIRECTION.md` (the art bible).
2. Read `docs/art/prompts/000-global-style.md` (the style token block).
3. Read the faction identity file for faction assets:
   `docs/art/prompts/factions/{acero,vinculados,marea-libre}.md`.

## Composing a prompt

Every prompt is:

```
<global style token block (verbatim)>
<faction identity block (if faction asset)>
<asset description>
RATIO: <16:9 | 4:3 | 1:1>
```

Never generate without the style tokens. Never change a faction's look without
editing its identity file first.

## Generating

Use the helper (recommended):

```bash
tools/gen-image.sh "<full prompt>" --output "$PWD/assets/<path>.png" --ratio 1:1 --name <slug>
```

Or call `agy` directly (same contract the helper encodes):

```bash
agy -p "<prompt>... End your reply with IMAGE_PATH: <absolute output path>" \
  --dangerously-skip-permissions --add-dir "$PWD"
```

## Gotchas (from the agy headless behavior)

- Headless `agy` self-denies tool use; it needs `--dangerously-skip-permissions`.
- `agy` ignores the shell working directory; always pass `--add-dir` **and**
  absolute output paths in the prompt itself.
- Generated files may land under `~/.gemini/antigravity-cli/...`; the helper
  moves them to `--output`. Verify the file exists and is a valid image after
  every run.
- Authentication: `agy` needs a signed-in account or `GEMINI_API_KEY` +
  `modelProvider: "gemini"` (see `docs/TECH.md`). Use `AGY_BIN` to override the
  binary path.

## After generating

Append a row to the asset log in the relevant prompt file:

```
| Asset | File | Ratio | Version | Date | Note |
```

Keep the prompt as the source of truth. Report deviations, do not hide them.
