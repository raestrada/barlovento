# AGENTS.md — BARLOVENTO Operating Manual

This file is the single source of truth for any LLM agent working in this
repository. Read it before doing anything else. All project content is in
**English**.

---

## 1. What this project is

**BARLOVENTO** is a **3D turn-based space strategy game**. The core fantasy is
naval warfare transposed to space: ships have **mass**, **inertia**,
**momentum** and **facing**, and positioning matters as much as firepower.

- **Turn-based**, not real-time.
- **Fully 3D** battles with a free camera.
- **Two combat phases**: a simultaneous "Admiral" phase for fleet
  positioning, then a turn-based "Ace" tactical phase for the actual fight.
- **Hero units** (a squad of 2-4 aces) that the player chooses and develops,
  in the spirit of *Gundam* — the ace pilots alongside the fleet.
- **Three asymmetric civilizations** with different hero types, aesthetics and
  relationships to the game's central resource ("the wind").

The full design is in [`docs/DESIGN.md`](docs/DESIGN.md). Read it before
writing gameplay code.

## 2. Lore in one paragraph

Space is not empty; it is a navigable sea — the **Star Sea** (*Mar Estelar*) —
a field of dark energy called **the Éther** ("the wind"). It is fading: a slow
front of decay, **the Calm**, is spreading, killing the wind wherever it
arrives. Three civilizations answer the crisis in three incompatible ways:

- **The Armada of Acero** (steel) — a hard-science navy that runs *on* the
  wind as an energy source ("the spice") and wants to dam and control it.
- **The Vinculados** (soul) — Gundam-style mecha pilots whose consciousness is
  coupled to the wind; they want to transcend before it dies.
- **The Free Tide** (*Marea Libre*, wind) — steampunk corsairs who sail the
  wind directly and want to re-awaken it.

Names, mechanics and full lore: [`docs/DESIGN.md`](docs/DESIGN.md).

## 3. Technology (fixed, do not change without approval)

- **Engine:** Godot **4.7.2-stable** — the latest stable release as of
  2026-10-13. Do **not** target 4.8-dev or 3.x.
- **Language:** GDScript.
- **Rendering:** Forward+.
- **Art:** no human artist exists on this project. All images, sprites,
  backgrounds and UI are generated by an agent orchestrating Google's
  Antigravity CLI (`agy`, Gemini). See §7 and
  [`docs/art/ART_DIRECTION.md`](docs/art/ART_DIRECTION.md).
- **Development model:** 100% LLM agents. Every change is made by an agent;
  keep everything reproducible from text (scenes, scripts, docs).

## 5. Working rules for agents

1. **English only.** Code, comments, commits, docs and prompts are written in
   English.
2. **Read before you write.** Gameplay code must follow
   [`docs/DESIGN.md`](docs/DESIGN.md); art must follow
   [`docs/art/ART_DIRECTION.md`](docs/art/ART_DIRECTION.md).
3. **No comments unless asked.** Prefer self-documenting names.
4. **GDScript style:** `snake_case` for functions and variables, `PascalCase`
   for classes and nodes, `CONSTANT_CASE` for constants, 4-space indentation.
5. **Do not change `docs/DESIGN.md` or lore silently.** Design changes go
   through the design document first.
6. **Never commit secrets** (API keys, tokens). Use environment variables
   (`GEMINI_API_KEY`, `AGY_BIN`).
7. **Verify with Godot when possible.** Headless checks:
   `godot --headless --path . --quit`.
8. **The title is a fixed image.** Whenever the name "BARLOVENTO" is shown
   (README, UI, cover, store), use the canonical wordmark
   `assets/brand/logo.png` (see `docs/art/prompts/logo.md`). Never re-typeset
   the title.

## 6. Design pillars (non-negotiable)

1. **Newtonian vector movement** — you order acceleration/heading, not
   teleporting to a point. Drift is a consequence, not an animation.
2. **Two phases** — simultaneous *Admiral* (positioning) then turn-based *Ace*
   (combat). Tactics can rescue strategy and vice versa (50/50 balance).
3. **Positioning that matters** — firing arcs, per-facing armor, mass and
   facing decide battles.
4. **Inertia as an obstacle to master** — every ship fights its own momentum.

## 7. Image generation workflow

There is **no human artist**. Images are produced by the **art-director**
agent, which orchestrates Gemini through the `agy` CLI. The rules:

- Every generated asset **must** come from a prompt registered under
  [`docs/art/prompts/`](docs/art/prompts/). Prompts are the source of truth
  and are versioned there.
- **Coherence over novelty:** reuse the global style tokens and per-faction
  identity files; never invent a new look ad-hoc.
- The canonical invocation is in
  [`.opencode/skill/image-generation/SKILL.md`](.opencode/skill/image-generation/SKILL.md)
  and `tools/gen-image.sh`.
- Output images go under `assets/` (see `assets/README.md`), never to temp
  paths.
