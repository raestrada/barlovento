# Faction — The Vinculados (soul)

## Identity block (include in every Vinculados prompt)

```
FACTION: The Vinculados — transhuman mecha pilots in the spirit of Gundam.
SHAPES: sleek, organic-curved humanoid mobile suits with exposed energy cores.
MATERIALS: white ceramic armor, dark sinew joints, glowing core.
ACCENT: cold magenta/violet for the soul-link energy.
MOOD: elegant, transhuman, slightly uncanny; duels between aces.
```

## Doctrinal notes for generation

- Mobile suits are humanoid but clearly mechanical; show the pilot-frame bond
  visually (shared light, matching core glow).
- Carriers and warships exist but are secondary; the frame is the icon.
- The soul-link is magenta/violet light; a linked frame's core and the pilot's
  eyes/cockpit glow in the same color.
